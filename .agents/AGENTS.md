# Agent Guidelines: Aegis Hub (Project Phoenix)

- **UI Framework**: Next.js App Router.
- **Styling**: Vanilla CSS (CSS Modules & Global CSS).
- **Theme**: Dark Mode strictly enforced.
- **Aesthetic Style**: Glassmorphism (blur backgrounds, semi-transparent overlays).
- **Typography**: "Outfit" font (Google Fonts).
- **Layout Requirements**: No flex squeezing. Preserve ad space. Functional, high-fidelity UI.
- **No Mock Data**: Ensure real or fully working integrations (no mock simulators).
